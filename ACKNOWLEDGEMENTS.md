# Acknowledgements and provenance

DcentWallpapers is a modified derivative of the GPL-2.0-only [Wallpaper Engine KDE plugin](https://github.com/catsout/wallpaper-engine-kde-plugin) created by catsout and its contributors.

Native scene rendering and system-audio support use the maintained GPL-2.0-only [CaptSilver fork](https://github.com/CaptSilver/wallpaper-engine-kde-plugin) and its renderer dependencies. The CaptSilver module is built and installed separately; its own source tree carries the applicable third-party notices and licenses.

DcentWallpapers changes include a Plasma 6 Configure interface, exact and repeatable KCM Apply transactions, selection-generation ownership, multi-screen routing, project-property and asset parsing, web compatibility bridges, clickable wallpaper forwarding, isolated scene preflight, safe fallback preparation, audio-spectrum integration, and first-frame backend handoff.
